# Инструкции для работы с проектом

## Технологический стек

- Java 17.
- Spring Boot 3.
- PostgreSQL.
- Flyway для управления миграциями базы данных.
- `BigDecimal` для всех денежных и ценовых значений.

## Правила изменений

- Не менять архитектуру проекта без предварительного согласования.
- Не добавлять библиотеки, если задачу можно решить существующими зависимостями.
- Не создавать избыточные абстракции; код должен оставаться простым и соответствовать текущим паттернам проекта.
- Новую функциональность сопровождать тестами в рамках той же задачи.
- Не изменять существующие миграции задним числом. Для изменений схемы создавать новую миграцию Flyway.
- Не выполнять `git commit` и `git push` самостоятельно.

## Проверка изменений

- После каждой задачи сообщать список изменённых файлов.
- Объяснять ключевые решения и указывать результаты выполненных тестов.
- Перед завершением задачи запускать подходящие проверки проекта, обычно `./mvnw test` (или `mvnw.cmd test` в Windows).
- Не считать задачу завершённой, если тесты падают, не объяснив причину и оставшийся риск.

## Область действия

Эти инструкции применяются ко всему проекту, если более специфичный `AGENTS.md` во вложенной директории не задаёт дополнительные правила.
